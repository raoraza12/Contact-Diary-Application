# Contact Diary Application

A simple static contact diary web app (HTML, CSS and vanilla JavaScript) with a register/login flow and a dashboard for managing contacts. Accounts and contacts are stored in the browser's localStorage, so it runs entirely client-side with no backend — just open `index.html` (or serve the folder with any static host, e.g. GitHub Pages) and register an account to get started. Note: passwords are stored in plaintext in localStorage by design for this demo, so do not use real passwords or treat it as a secure system.
